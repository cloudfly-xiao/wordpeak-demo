# 词峰 WordPeak · 高中英语单词集训系统（演示版）

> 面向高中生的科学单词集训工具：三种训练模式 + 简化 SM-2 间隔复习 + 学情统计，让背单词像闯关一样上瘾。本仓库为 **Web 端可演示产品**，打开即用、无需任何后端与 API Key。

## 一、产品定位

「词峰」是一款面向高中生的英语单词集训系统。区别于"翻卡片式"背单词工具，词峰以 **训练制** 为核心：看词选义、听音识词、拼写挑战三种模式覆盖"认读—听力—输出"完整记忆链路；答错的词自动进入错词本并可闪电重练；内置简化 SM-2 间隔复习算法，答对的词间隔翻倍、答错的次日重现，用最少的复习次数锁住长期记忆；配合打卡与近 7 天学情统计，帮助学生养成每天一组的学习节奏。

## 二、功能清单（Web 端已实现）

| 模块 | 说明 |
| --- | --- |
| 首页 | 问候+日期、今日任务环形进度（渐变描边动画）、连续打卡火焰、今日正确率、词库进度；四大训练模式入口（渐变图标磁贴+角标）；到期复习横幅；10 个单元词书卡片与学习进度条 |
| 看词选义 | 显示单词 + 音标，四选一选词义，即时判定动画（答对绿色渐变弹跳+连击计数 / 答错红色抖动并呼吸灯高亮正确项、其余选项压暗），答完例句卡滑入并自动朗读；组内答错的词自动加练一次；组完成彩带庆祝+奖杯 |
| 听音识词 | Web Speech API（浏览器本地 TTS）自动播报发音，点击大喇叭可重听，选出词义后展示单词拼写与例句 |
| 拼写挑战 | 看释义 + 听发音，卡片式字母格逐格填充动画：拼对字母才点亮，拼错红闪抖动；支持"提示一个字母""跳过"；完成后展示音标与例句 |
| 错词本 | 答错自动收集，记录错误次数，行内发音按钮；答对一次自动移出；支持一键"重练错词"；空状态含引导插画 |
| 间隔复习 | 简化 SM-2：答对间隔翻倍（1→2→4→8…天，上限 64 天），答错重置为 1 天次日重现；首页横幅 + 复习页展示今日待复习数量、即将到期词表与机制说明 |
| 统计 | 四宫格数据卡；近 7 天柱状图（渐变柱+数值气泡）；掌握程度环形图（SVG stroke-dasharray 动画）；GitHub 风格学习热力图（近 5 周） |
| 深浅色主题 | 跟随系统 + 手动三态切换（自动/浅色/深色），防闪烁预加载 |
| 数据持久化 | 全部学习记录使用 localStorage 本地存储，刷新不丢失（兼容 v1 数据） |
| 词库 | 内置高中英语核心词 160 个，含音标、中文释义、英文例句，按 10 个主题单元分组（性格品质 / 学业 / 行为 / 情感 / 自然环境 / 科技 / 健康 / 职业经济 / 旅行文化 / 高频冲刺） |
| 界面 | 中文界面，CSS 设计令牌体系（色板/字号阶梯/8px 栅格/圆角/阴影层级），全内联 SVG 线性图标，移动端优先并自适应桌面宽屏 |

## 四、技术说明

- **纯静态、零依赖**：原生 HTML/CSS/JS 三个文件 + 内置词库 JS，无框架、无构建、无网络请求，双击 `index.html` 或任一静态服务器即可运行。
- **发音**：浏览器 Web Speech API（`speechSynthesis`），本地合成，不调用任何在线 TTS 服务。
- **持久化**：`localStorage`（key: `wordpeak_v1`），存储词态（间隔/到期时间/对错次数）、错词本、每日统计。
- **算法**：简化 SM-2 间隔重复；掌握判定为当前复习间隔 ≥ 4 天。
- **目录结构**：

```
demo/word-trainer/
├── index.html        # 页面骨架（顶栏 / 主视图 / 底部导航 / 弹层）
├── css/style.css     # 全部样式（设计变量 / 组件 / 动画 / 响应式）
├── js/words.js       # 内置词库：160 词 × 10 单元（单词/音标/释义/例句）
├── js/app.js         # 业务逻辑（路由 / 四种会话 / SM-2 / 统计 / TTS）
└── README.md
```

- 本地运行：`python -m http.server 8787 --directory demo/word-trainer` 后访问 `http://localhost:8787`（或直接双击 index.html）。

## 五、三端架构规划

```
            ┌────────────── 共用层 ──────────────┐
            │  词库 JSON（160+词，可持续扩充）      │
            │  题目生成 / SM-2 调度 / 统计口径      │
            └───────┬──────────┬──────────┬──────┘
                    │          │          │
        ┌───────────▼──┐  ┌────▼─────────┐  ┌▼──────────────┐
        │ 学生 Web 端   │  │ 微信小程序端  │  │ 教师后台 Web   │
        │ ✅ 已实现      │  │ 规划中        │  │ 规划中         │
        └──────────────┘  └──────────────┘  └───────────────┘
                    ▲          ▲                  ▲
                    └── 学生端数据同步（云开发/轻后端） ──┘
```

### 1. 学生 Web 端（本次交付，已实现）

纯静态 SPA，可部署至任意静态托管（OSS / CDN / GitHub Pages）。词库与算法层独立成 `words.js` 数据文件与无副作用函数，可直接复用到其他端。

### 2. 微信小程序端（落地路线）

- **框架**：uni-app（Vue3）或 Taro（React），复用 Web 端的词库 JSON 与 SM-2 调度逻辑（纯 JS 可直接移植）。
- **UI**：迁移现有设计语言， tabBar 对应 首页 / 复习 / 错词本 / 我的统计。
- **发音**：优先使用微信同声传译插件（`WechatSI`）实现本地文字转语音；备选方案为预生成音频文件存放于 CDN/云存储，`InnerAudioContext` 播放。
- **数据同步**：接微信云开发（云数据库 + 云函数），openid 自动识别；离线时 localStorage（`wx.setStorageSync`）优先、登录后合并上传，实现 Web/小程序双端进度同步。

### 3. 教师后台（落地路线）

- **技术栈**：React + Ant Design Pro + 云开发 serverless（或轻量 Node 服务 + PostgreSQL）。
- **核心能力**：班级与学生管理（邀请码/批量导入）、词库与单元管理（增删改查、批量导入 Excel）、作业布置（指定单元 + 模式 + 截止时间）、学情报表（正确率、错词 Top 榜、连续打卡、近 7 天趋势）、AI 错因提示（高频混淆词对推荐）。
- **权限**：教师 / 年级组长 / 校管理员三级角色。

## 六、运行与演示说明

1. 解压后在 `demo/word-trainer` 目录任选其一：
   - 直接双击 `index.html`；
   - 或 `python -m http.server 8787`，浏览器打开 `http://localhost:8787`。
2. 推荐使用 Chrome / Edge 演示（Web Speech API 发音效果最佳）。
3. **演示提示**：首次打开为空白学习记录，可任选单元练习几题后查看错词本与统计页效果。

> **声明**：本作品为投标演示版。所有学习数据仅保存在浏览器本地（localStorage），不上传任何服务器；词库内容为演示用途的高频高中词汇。
